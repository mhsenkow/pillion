# Weekly couch playtest

The TV + phone test is the source of truth.

## Checklist

1. Cast the TV page (`?tv=1`) to a real TV.
2. Share / scan the QR; gunner joins from a phone.
3. Drive one Emmett block; confirm radar stays live.
4. Fire BREACH / TESLA / BOMB; confirm haptics and TV laser.
5. Drop a destination (Detroit or Chicago); confirm compass + ETA.
6. Note frame hitches, join friction, and anything that feels “not a couch game.”
7. File findings as a GitHub issue titled `Couch playtest YYYY-MM-DD`.
